# Code of Conduct

Tiny Rogues Training Dummy is a community project. We want contributions and discussions to be welcoming, practical, and respectful.

Expected behavior:

- Be considerate of different experience levels and perspectives.
- Give actionable feedback about the code, documentation, or game behavior.
- Credit other contributors and respect the licenses of reused work.
- Keep discussions focused on improving the mod and helping players.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, spam, and sharing private information without permission.

If a problem occurs, contact the repository maintainer privately through the maintainer's GitHub profile. Do not use a public issue to report a personal or safety concern. Reports will be reviewed and handled as confidentially as practical.
