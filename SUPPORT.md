# Support

For installation and gameplay problems, open a [bug report](https://github.com/tannerbyers/tinyrogues-training-dummy/issues/new?template=bug-report.yml).

Before reporting:

- confirm the mod matches your Tiny Rogues and BepInEx versions
- reproduce the problem with the current release
- include your platform and relevant lines from `BepInEx/LogOutput.log`
- remove unrelated personal paths or information from logs

Feature ideas and questions are welcome as GitHub issues. Please check existing issues first.
