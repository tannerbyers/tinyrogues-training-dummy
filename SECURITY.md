# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner privately through their GitHub profile or GitHub's private vulnerability reporting feature if it is enabled for this repository.

Include the affected release or commit, reproduction steps, expected and observed behavior, and logs or proof of impact that do not contain personal information.

Please allow time for the issue to be confirmed and addressed before public disclosure. This mod does not handle accounts, payments, or remote services, but reports involving unsafe files, installation behavior, or unintended game/system access are welcome.
